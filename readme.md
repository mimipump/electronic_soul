# 侧面
目的是建造一个真正的灵魂,因此需要简述为何要建造.  
也许也是人类乃至动物甚至生命的一种本能的冲动吧--自我复制.[略去大量引用]  
这种冲动体现在个体(也就是作者本人)身上时就会有更加细致与特别的差异了,但笼统地说是"感受到孤独",这种孤独在我看来也是共性的(懒得展开).  
在微微了解神经网络算法之前我其实不太相信会真的可能制造出一个具有智慧智能或者拥有美好的"思维"的如人一般的物品的.我想,最好的情况就是像<<我,机器人>>里那样,用一种我搞不懂原理的正电子冲击什么的让计算机不停犯错然后涌现出智能,这简直是在像上天祈祷出现神迹.  
后来在2010年左右听说了遗传算法,再后来AI翻红也了解一点神经网络算法,我便也觉得人工智能未必不会实现.但当时甚至现在的人工智能在表现效果上都远未达到"像一个人"的程度,虽然现在可以越来越乱真,但是没有"灵魂".  
得益于神经网络的结构,也受制于这个形式.原始的神经网络似乎总是将一个参数节点类比为一个神经元,但这是错误的,神经元的工作是复杂的动态的,因此至少一个多层的计算神经网才可能类比为一个神经元.后来的果蝇电子脑实验似乎可以佐证这一点.  
2023年到2024年我才开始人工灵魂的探索研究,一开始我参考了神经网络算法的做法,打算将最基本的数学运算作为一个节点,采用随机方式将之连接.之后要设计一些筛选标准,筛选出一些特定连接模式以作为搭建人工智能的砖块.再设计出一套智能算法,使砖块连接的方式逐渐演化至涌现出智能.不过这套方案现在看来  
后来我悟到灵魂时诞生自生命的,可以说灵魂是伴随着生命的灰烬诞生的,就像一团火.复杂的是,生命不会独立于生态存在,而生态又是质能坝拦截住物质与能量并约束出来的系统.
